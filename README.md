# 🔎 FiyatRadar

FiyatRadar, farklı e-ticaret platformlarındaki ürünleri karşılaştırmayı ve kullanıcıların uygun fiyatlı seçeneklere daha kolay ulaşmasını amaçlayan bir web uygulamasıdır.

🌐 **Canlı Demo:** https://fiyat-radar-sekiz.vercel.app/

## 🚀 Özellikler

- Ürün arama
- Farklı mağazalardaki ürünleri görüntüleme
- Fiyat karşılaştırma
- Ürün fiyatlarını sıralama
- Ürün stok ve bağlantı bilgilerini görüntüleme
- Responsive web arayüzü

## 🛠️ Kullanılan Teknolojiler

- Next.js
- TypeScript
- Tailwind CSS
- Playwright
- Vercel

## 💡 Projenin Amacı

FiyatRadar, kullanıcıların aynı veya benzer ürünleri farklı e-ticaret platformlarında tek tek aramak yerine daha kolay karşılaştırabilmesi amacıyla geliştirilmiştir.

Proje aynı zamanda web geliştirme, veri toplama, kullanıcı arayüzü geliştirme ve farklı kaynaklardan gelen verilerin işlenmesi konularında deneyim kazanmak amacıyla geliştirilmiştir.
